# Rhodep Linux 6.1 prebuilts

Generated with the [Sedona kernel builder](https://github.com/Motorola-Sedona61/kernel_build) from the [kernel manifest](https://github.com/Motorola-Sedona61/kernel_manifest). The `6.1` directory is consumed by the Android board configuration.

Rebuild with `./build.sh RHODEP` in a synced kernel workspace. The matching Image, DTs, modules and exported headers must be kept together. Build completion does not establish device compatibility.
